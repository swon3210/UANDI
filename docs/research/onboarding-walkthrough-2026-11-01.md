## 2. 로그인 직후 — 커플 연결 (`/onboarding`)

### 2-1. A: 새 커플 공간 만들기 → 코드 대기

실제 행동(A): 코드 생성 → 복사 → **새로고침** → 혼자서 대시보드 진입 → 투어 팝업.
(코드 생성 시점에 user.coupleId가 이미 박히므로 새로고침하면 with_couple로 판정돼 들어가진다. 화면은 그걸 알려주지 않는다.)

- 막힌 점: 코드 화면은 "상대방이 입력하면 자동으로 연결됩니다" 스피너만 돌고 출구가 없다. 상대가 지금 옆에 없으면 할 수 있는 게 없어 새로고침으로 뚫고 들어감.
- 기대했던 경험: 코드를 복사해 보내 놓고 **나 혼자 먼저 둘러보기/시작하기**를 눌러 들어가고 싶다. 상대는 나중에 합류해도 된다.
- 아이디어: 코드 화면에 "먼저 시작하기" 버튼 추가(새로고침 없이 진입). 들어간 뒤에도 상대가 아직 없으면 대시보드 상단에 "OO님을 기다리는 중 · 코드 ABC123 [복사] [공유]" 카드로 초대 상태를 계속 보여주기.

### 2-2. B: 초대 코드 입력 → 합류

실제 행동(B=진성): 로그인 → 선택 화면 → [초대 코드 입력하기] → QMDWDW 입력 → [연결하기] → **곧바로 대시보드 + 투어 1장**.

- 막힌 점:
  - 선택 화면에서 primary(코랄)가 "새 커플 공간 만들기"다. 코드를 받고 들어온 사람도 습관적으로 위 버튼을 누르기 쉽고, 그러면 혼자짜리 커플이 하나 더 생긴다(되돌리는 UI 없음).
  - 코드 입력 화면에 "누구의 초대인지"가 안 보인다. 6자리 맞게 쳤는지 확인할 단서가 없다.
  - 연결 성공 순간이 없다. "test님과 연결됐어요" 같은 한 박자 없이 바로 투어 오버레이가 덮는다. 투어 뒤에 깔린 대시보드의 커플 카드(test · 진성)는 투어를 다 넘기거나 건너뛴 뒤에야 보인다.
  - 랜딩에서 A가 로그인할 때 쓴 '구글로 시작하기' 흐름은 브라우저 패인에서 팝업이 막혀 B는 이메일 로그인으로 우회했다(에뮬레이터 한계, 제품 문제 아님).
- 기대했던 경험: 코드를 치면 "test님이 초대한 공간이 맞나요?" 확인 → 연결 축하 한 장(마스코트 둘) → 그 다음에 뭘 할지 안내.
- 아이디어:
  - 초대 링크(코드가 박힌 URL)로 공유하면 B는 링크 → 로그인 → 자동 합류. 코드 타이핑 자체를 없앤다.
  - 초대받은 사람 경로를 선택 화면에서 분리: "초대받으셨나요? 코드 입력" 링크를 위로, 공간 만들기는 아래로.
  - 연결 완료 화면 1장을 투어 앞에 둔다(두 마스코트 + 두 이름).

## 3. 투어 슬라이드 7장

실제 행동(B=진성): 연결 완료 → 시작하기 → 대시보드를 보기도 전에 투어 1장이 덮음 → 7번 "다음" → 시작하기 → 빈 대시보드.

- 막힌 점 (Claude 관찰):
  - **순서**: 연결 완료 화면 직후 투어가 바로 덮는다. 방금 "세진님과 연결됐어요"를 봤는데 그 결과(커플 카드)를 확인할 틈 없이 7장짜리 설명이 시작된다.
  - **스크린샷 슬라이드(2~5장)가 현재 UI와 다르다**: 스크린샷엔 상단 분류 탭(대시보드/내역/현금흐름/목표)이 있는데, main은 #295에서 그 탭을 없앴다. 투어가 보여주는 화면과 실제 화면이 다르다.
  - 스크린샷이 190px 폭이라 모바일에서 글자가 안 읽힌다. "데이터가 찬 화면"을 보여주는데, 유저가 곧 만날 화면은 텅 빈 대시보드라 연결이 안 된다.
  - **용어 불일치**: 1장은 "내역 입력·결산·예측"이라 하고 5장 제목은 "점검하기"다. 결산=점검인지 신규 유저는 모른다.
  - 5장 "점검하기"는 "(선택) 취소내역·누락내역을 검증"이라는 고급 기능 설명이다. 첫날 유저에겐 뜻도 필요도 없다. 6장 "그 외 기능(베타)" 갤러리·재테크·커뮤니티도 첫 진입에선 산만함만 더한다.
  - **끝이 행동으로 이어지지 않는다**: 7장 "이제 시작해볼까요?" → 시작하기 → 빈 대시보드. 뭘 먼저 하라는 말이 없다. (그 다음 진입에서야 예산 위저드로 강제 이동. 4구간 참고)
  - 7번 탭해야 끝난다. 건너뛰기를 누를 확률이 높고, 건너뛰면 아무것도 남지 않는다.
- 막힌 점 (A 시점):
- 기대했던 경험: 연결 직후엔 커플 카드를 먼저 보고, 투어는 3장 이내로 "첫 내역을 넣어 보자"로 끝나거나, 아예 빈 화면 위에 붙은 행동 유도로 대체.
- 아이디어:
  - 투어를 "기능 카탈로그"에서 "첫 행동 안내"로 바꾸기: 1) 둘이 같이 쓰는 가계부예요 2) 첫 내역을 넣어 보세요(+ 버튼 가리키기) 3) 예산은 나중에 설정에서. 점검·베타 기능은 빼고 필요할 때 해당 화면에서 처음 1회 안내.
  - 스크린샷 대신 현재 화면 위에 하이라이트(코치마크)로 안내하면 UI가 바뀌어도 어긋나지 않는다.
  - 투어 노출 시점을 "연결 직후"가 아니라 "대시보드가 한 번 그려진 뒤" 또는 "첫 + 버튼 근처"로.

## 4. 빈 대시보드 — 첫 행동 찾기

실제 행동(세진, 혼자 시작): 가져오기로 3건 저장 → 대시보드(토스트 "3건 추가됐어요") → 1.5초 뒤 투어 3장 → 둘러볼게요 → 대시보드 → 다시 진입 → **연간 예산 위저드로 자동 이동** → X(위저드 종료) → "2026년 경제 목표" 페이지(0원 플랜).

- 막힌 점 (Claude 관찰):
  - **투어 2장이 방금 한 일과 어긋난다.** 가져오기로 내역을 넣었는데 "첫 내역을 적어 볼까요?"가 뜬다. 내역이 이미 있으면 2장은 "내역이 들어왔어요 → 내역 화면에서 확인"으로 바뀌거나 빠져야 한다.
  - **지난달 내역을 가져왔는데 대시보드는 이번 달을 보여준다.** 가져온 내역이 지난달 날짜면 도착한 대시보드는 다시 "이 기간엔 내역이 없어요"다(이번 걷기에선 어제 날짜 건이 10월로 빠져 11월 화면에 안 보였다). 저장 직후엔 내역이 있는 달로 보내거나 "10월 내역 N건이 들어왔어요 → 10월 보기" 배너가 필요하다.
  - **투어 다음 진입에 예산 위저드로 강제 이동.** 27개 카테고리 × 12개월 그리드, 4단계. 첫 주 유저에게 무겁고, 투어 3장이 "예산은 곧 같이 세울 거예요"라고 했지만 '곧'이 바로 다음 진입이라 당황스럽다.
  - **위저드 X를 누르면 0원짜리 빈 플랜이 남고 경제 목표 페이지에 떨어진다.** 플랜이 생겼으니 위저드는 다시 자동으로 안 뜨고, 이후 예산 진입은 프로필 → 설정 → 경제 목표로 깊다. 즉 한 번 X를 누르면 "예산은 나중에"가 "예산은 영영 못 찾음"이 되기 쉽다.
  - 대시보드 자체에는 다음 행동 유도가 없다. 데이터가 있을 땐 수입 대비 지출 미터, 없을 땐 빈 상태 + 가져오기 버튼뿐. 예산·현금흐름·점검으로 가는 길은 보이지 않는다(사이드바·설정에 숨어 있음).
- 막힌 점 (A 시점):
- 기대했던 경험: 가져온 내역이 바로 보이고, 예산은 "세울래요?" 카드로 권유받되 강제되지 않으며, 미루더라도 대시보드에서 다시 찾을 수 있어야 한다.
- 아이디어:
  - 가져오기 저장 후 내역이 있는 달로 이동(또는 배너).
  - 위저드 자동 이동을 없애고 대시보드 상단에 "올해 예산 세우기 (5분)" 카드로 대체. 카드는 플랜이 생길 때까지 남고, 닫기는 가능하되 설정에서 다시 켤 수 있게.
  - 위저드 X가 빈 플랜을 남기지 않게(인트로에서 나가면 플랜 미생성).
  - 투어 2장을 상태 인식형으로: 내역 0건이면 "첫 내역 적기", 있으면 "내역 확인하기".
- 발견(Claude, 구현 중): 대시보드 진입 훅(`useCashbookEntryAutoOpen`)이 투어를 본 다음 진입에서 **올해 예산 플랜이 없으면 연간 예산 위저드로 자동 이동**시킨다(연 1회). 즉 신규 유저는 "투어 7장 → 빈 대시보드 잠깐 → 위저드 인트로"를 연달아 겪는다. 첫 행동을 강제로 정해 주는 셈인데, 이게 맞는 첫 행동인지(첫 내역 입력이 먼저인지)는 이 구간을 걸으며 판단한다.

## 5. "첫 주" — 첫 내역 입력, 카테고리, 연간 예산

걸은 경로: 가입 → 처음 시작해요 → 먼저 시작하기 → 가져오기 건너뛰기 → 투어 3장 → "첫 내역 적기" → 빠른 추가 → 내역 화면 → 프로필 메뉴 → 설정 → 가계부 설정 → 카테고리 설정 → 대시보드 권유 카드 → 예산 위저드(수입 3항목까지) → X 종료 → 경제 목표 → 대시보드.

- 확인됨: 투어 마지막 장 "첫 내역 적기" → 빠른 추가 시트가 바로 열린다. 저장 후 "1건 추가됐어요" 토스트, 내역 화면에 작성자 배지("진")와 함께 보인다. 카테고리 설정 화면은 공통/각자 섹션과 설명이 있어 이해하기 쉽다. 위저드 그리드는 평균값 자동 채움, 비정기 항목은 "연 합계 → 채우기"가 있다.
- 막힌 점:
  - 빠른 추가의 화살표 버튼이 입력이 비면 "직접 입력", 차면 "AI 파싱"으로 역할이 바뀌는데 아이콘은 같다. 금액·카테고리를 직접 고르고 싶은 사람은 수동 폼으로 가는 길을 못 찾는다.
  - 첫 지출 1건을 적자마자 대시보드에 "🚨 이 기간엔 수입이 없어요"(`IncomeExpenseMeter`). 첫 주에 수입을 아직 안 적었을 뿐인데 경고로 읽힌다.
  - 방금 적은 내역이 대시보드엔 안 보인다(요약 카드만). 토스트에 "보기" 액션도 없어 헤더 "내역"을 찾아야 한다.
  - 내역 화면 "잔액 -9,000원"은 월 수입−지출인데 통장 잔액처럼 읽힌다.
  - 폼에서 식비를 공통/각자 중 골라도 `CashbookEntry.category`는 이름 문자열뿐이라 저장 후 구분이 사라진다. `useDashboardData`는 이름으로 합산해 공통 식비·각자 식비가 하나로 섞인다. 기본 카테고리에 식비·여가가 두 그룹에 각각 있어 첫 주부터 충돌한다.
  - 권유 카드는 "약 5분"인데 위저드 인트로는 "총 26개 카테고리", 정기 항목은 평균+그리드 2단계라 40단계 안팎. 건너뛰기가 없고 평균 0원인 항목(상여)도 12개월 그리드를 한 번 더 거친다.
  - 수입 3항목만 넣고 X로 나오면 경제 목표 페이지가 "예상 연간 잉여 +3,600만원 / 지출 한도 −0"을 보여 준다. 인트로는 "언제든 종료해도 이어서 할 수 있어요"라 했는데 페이지엔 "처음부터 다시 세우기"뿐이고 이어서 할 진입점이 없다. 플랜이 생겼으니 대시보드 권유 카드도 사라져 미완 상태를 알 길이 없다.
  - 정기급여 단계에 두 사람 월급을 합쳐 적는지 안내가 없다(공동 가계부).
  - 설정 첫 화면에 "회원탈퇴"가 빨간 글씨로 바로 보인다.
  - 투어 1장 "짝꿍님과 같은 가계부를 봐요"는 먼저 시작한 사람(아직 미초대)에겐 해당이 없다.
  - 접근성: 사이드바 링크 7개, 프로필 메뉴 "설정", 시트 닫기(X), 위저드 그리드 12칸의 접근성 이름이 없거나 "0"이다.
  - 개발 환경 한정: 페이지 첫 진입마다 10~30초 컴파일 동안 문구 없는 스피너만 보인다. 프로덕션은 짧지만 전환 스피너에 문구가 없는 건 같다.
- 기대했던 경험: 첫 내역을 적으면 "어디 갔는지" 바로 보이고, 첫 주엔 꾸중 대신 "수입도 적어볼까요?" 정도의 권유. 예산은 5분 안에 큰 숫자 몇 개(월급·월세·식비)만 넣고 나머지는 나중에 채우는 흐름.
- 아이디어:
  - 빠른 추가 시트에 "직접 입력" 텍스트 버튼을 따로 두고 화살표는 AI 보내기로만 쓴다.
  - 내역이 적은 첫 달(예: 5건 미만)엔 🚨 대신 중립 문구와 "수입 적기" 링크. 토스트에 "보기" 액션.
  - 대시보드 요약 카드 아래 "최근 내역 3건" 섹션.
  - 내역에 `categoryId`(또는 subGroup) 저장, 집계도 id 기준. 기본 카테고리 중복 이름(식비·여가)은 "식비(공동)/식비(각자)"처럼 구분하거나 하나로 합친다.
  - 위저드 "빠른 예산" 모드: 월급·월세·식비 등 상위 5~6개만 묻고 나머지는 0으로 두고 완료. 0원 항목은 그리드 생략, 항목 "건너뛰기" 버튼.
  - 미완 플랜이면 권유 카드를 "예산 이어서 세우기 (3/26)"로 바꾸고, 경제 목표 페이지에도 "이어서 하기" 버튼.
  - 정기급여 단계 설명에 "두 사람 월급을 합쳐 적어요".
  - 회원탈퇴는 프로필 상세 하단으로 이동.

### 지난 내역 가져오기 추가 (2026-11-01, 4구간 선반영)

걷기 중 나온 요청: 온보딩에서 통장·카드 내역을 올려 내역 추가 + 카테고리 초기화를 한 번에.

- 발견: 신규 커플은 **카테고리 0개**로 시작했다(기본 카테고리 초기화 함수를 부르는 곳이 없었음). 그래서 내역을 올려도 전부 미분류로 떨어질 상황이었다. → 커플 생성 시 기본 카테고리를 초기화하도록 수정.
- 새 화면 `/inner/cashbook/import`(3단계: 올리기 → 카테고리 확인 → 내역 확인). 연결 완료 "시작하기"와 "먼저 시작하기"가 여기로 오고, 건너뛰면 대시보드. 빈 대시보드에 "지난달 내역 불러오기" 버튼.
- 카테고리 추론: 기본 카테고리를 후보로 넘기고 AI가 맞는 게 없을 때만 새 카테고리를 제안(`allowNewCategories`). 제안은 이름·구분(고정/공통/각자)을 고치거나 뺄 수 있고, 뺀 내역은 `기타`로.
- 명세: `docs/pages/inner/cashbook-import.md`.
