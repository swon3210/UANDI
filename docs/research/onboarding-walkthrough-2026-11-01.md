## 2. 로그인 직후 — 커플 연결 (`/onboarding`)

### 2-1. A: 새 커플 공간 만들기 → 코드 대기

실제 행동(A): 코드 생성 → 복사 → **새로고침** → 혼자서 대시보드 진입 → 투어 팝업.
(코드 생성 시점에 user.coupleId가 이미 박히므로 새로고침하면 with_couple로 판정돼 들어가진다. 화면은 그걸 알려주지 않는다.)

- 막힌 점: 코드 화면은 "상대방이 입력하면 자동으로 연결됩니다" 스피너만 돌고 출구가 없다. 상대가 지금 옆에 없으면 할 수 있는 게 없어 새로고침으로 뚫고 들어감.
- 기대했던 경험: 코드를 복사해 보내 놓고 **나 혼자 먼저 둘러보기/시작하기**를 눌러 들어가고 싶다. 상대는 나중에 합류해도 된다.
- 아이디어: 코드 화면에 "먼저 시작하기" 버튼 추가(새로고침 없이 진입). 들어간 뒤에도 상대가 아직 없으면 대시보드 상단에 "OO님을 기다리는 중 · 코드 ABC123 [복사] [공유]" 카드로 초대 상태를 계속 보여주기.

### 2-2. B: 초대 코드 입력 → 합류

실제 행동(B=진성): 로그인 → 선택 화면 → [초대 코드 입력하기] → QMDWDW 입력 → [연결하기] → **곧바로 대시보드 + 투어 1장**.

- 막힌 점:
  - 선택 화면에서 primary(코랄)가 "새 커플 공간 만들기"다. 코드를 받고 들어온 사람도 습관적으로 위 버튼을 누르기 쉽고, 그러면 혼자짜리 커플이 하나 더 생긴다(되돌리는 UI 없음).
  - 코드 입력 화면에 "누구의 초대인지"가 안 보인다. 6자리 맞게 쳤는지 확인할 단서가 없다.
  - 연결 성공 순간이 없다. "test님과 연결됐어요" 같은 한 박자 없이 바로 투어 오버레이가 덮는다. 투어 뒤에 깔린 대시보드의 커플 카드(test · 진성)는 투어를 다 넘기거나 건너뛴 뒤에야 보인다.
  - 랜딩에서 A가 로그인할 때 쓴 '구글로 시작하기' 흐름은 브라우저 패인에서 팝업이 막혀 B는 이메일 로그인으로 우회했다(에뮬레이터 한계, 제품 문제 아님).
- 기대했던 경험: 코드를 치면 "test님이 초대한 공간이 맞나요?" 확인 → 연결 축하 한 장(마스코트 둘) → 그 다음에 뭘 할지 안내.
- 아이디어:
  - 초대 링크(코드가 박힌 URL)로 공유하면 B는 링크 → 로그인 → 자동 합류. 코드 타이핑 자체를 없앤다.
  - 초대받은 사람 경로를 선택 화면에서 분리: "초대받으셨나요? 코드 입력" 링크를 위로, 공간 만들기는 아래로.
  - 연결 완료 화면 1장을 투어 앞에 둔다(두 마스코트 + 두 이름).

## 구현 반영 (2026-11-01, 1~2구간 지적 사항 전부)

걷기 3~6구간(투어·빈 대시보드·첫 주·상대 화면)은 아직 걷지 않았다. 1~2구간에서 나온 지적은 모두 반영했다.

| 지적                                          | 반영                                                              | 위치                                          |
| --------------------------------------------- | ----------------------------------------------------------------- | --------------------------------------------- |
| 랜딩에 "가계부"가 없고 내부 용어·옛 로고      | 마스코트 + "둘이 함께 쓰는 말랑 가계부" + 기능 3줄                | `components/landing/LandingHero`              |
| 코드 화면에 출구가 없어 새로고침으로 진입     | **먼저 시작하기**(새로고침 없이 진입) + 링크 공유                 | `InviteCodePanel`, 온보딩 2A                  |
| 들어간 뒤 초대 상태가 안 보임                 | 대시보드 초대 카드 → 코드 시트, 합류 시 실시간 전환 + 토스트      | `CoupleStatusSection`, `useCoupleConnection`  |
| 선택 화면 primary가 "새 공간"이라 오누름 유도 | 같은 무게의 선택 카드 2개(처음 시작 / 코드 받음)                  | `OnboardingChoiceCard`                        |
| 코드 입력 시 누구의 초대인지 모름             | 6자리 입력 시 "OO님의 초대예요" 미리보기                          | `InviteCodeHint`, `inviteCodes.createdByName` |
| 연결 성공의 순간이 없음                       | 연결 완료 화면(두 마스코트 + 시작하기), 양쪽 모두                 | `CoupleConnectedState`, 온보딩 3단계          |
