# 국제화 (i18n) — 한국어 / 영어

말랑 가계부는 한국어(기본)와 영어 UI 를 제공한다. 범위는 **A: UI 언어만** 이다.
금액은 원화(KRW) 고정이고 표기 방식만 바뀐다. 전체 계획·결정 경위는
`docs/research/i18n-english-plan-2026-11-11.md` 참고.

---

## 1. 로케일 결정 (URL prefix 없음)

`/en/...` 같은 URL 프리픽스는 쓰지 않는다. 모바일 WebView 딥링크(`uandi-web.vercel.app` intent filter),
`middleware.ts` 경로 규칙, E2E 경로가 전부 깨지기 때문이다.

요청마다 `apps/web/src/i18n/request.ts` 가 아래 순서로 정한다.

| 순서 | 소스                | 설명                                                   |
| ---- | ------------------- | ------------------------------------------------------ |
| 1    | 쿠키 `uandi-locale` | 설정 화면에서 고른 값. 1년 유지                        |
| 2    | `Accept-Language`   | 첫 방문(쿠키 없음). 모바일 WebView 는 기기 언어가 온다 |
| 3    | `'ko'`              | 기본값                                                 |

로그인 사용자의 선택은 **`users/{uid}.locale`** 에도 저장한다. 이 값이 서버(AI 라우트·Cloud Functions 푸시)가 읽는 단일 소스다.
`AuthInit` 은 로그인 시 문서 값과 쿠키가 다르면(새 기기·쿠키 삭제) 쿠키를 문서 값으로 맞추고 `router.refresh()` 한다.

공통 상수·유틸: `apps/web/src/lib/locale.ts` (`LOCALES`, `DEFAULT_LOCALE`, `LOCALE_COOKIE`, `resolveLocale`, `getActiveLocale` …)

## 2. 기술 구성

| 영역                  | 선택                                                    | 비고                                                                      |
| --------------------- | ------------------------------------------------------- | ------------------------------------------------------------------------- |
| web                   | `next-intl` 4.x, 라우팅 없이 `getRequestConfig`         | `next.config.ts` 의 `createNextIntlPlugin('./src/i18n/request.ts')`       |
| 루트 레이아웃         | `getLocale()` → `<html lang>`, `NextIntlClientProvider` | `generateMetadata` 도 `getTranslations('metadata')`                       |
| 타입                  | `apps/web/src/i18n/next-intl.d.ts`                      | `useLocale()` 이 `Locale`, 메시지 키가 ko JSON 기준으로 타입 검사됨       |
| packages/ui Storybook | `NextIntlClientProvider` 데코레이터 + 툴바 Locale(🌐)   | `packages/ui/.storybook/preview.tsx`. web 의 `messages/` 를 그대로 읽는다 |
| dayjs                 | `LocaleSync` 가 `dayjs.locale(locale)` 동기화           | 서버 렌더는 `utils/date.ts` 초기값 'ko'                                   |

## 3. 메시지 파일

```
apps/web/messages/
├── ko/
│   ├── common.json      # 공통 버튼·앱 이름
│   ├── metadata.json    # <title>, description, manifest
│   ├── settings.json    # /settings, 프로필 편집, AI 설정 페이지
│   ├── shell.json       # 헤더·사이드바·프로필 메뉴
│   ├── landing.json     # 랜딩(비로그인)
│   ├── onboarding.json  # 온보딩 + 초대 공유 문구
│   ├── tour.json        # 온보딩 투어 3장
│   ├── pwa.json         # 홈 화면 추가 안내
│   ├── ui.json          # packages/ui 컴포넌트(사이드바·다이얼로그 닫기·온보딩·아바타·AI 설정 knob)
│   └── dashboard.json   # 대시보드(기간·그룹·도넛·기간 비교·AI 요약·넛지·커플 카드)
└── en/                  # ko 와 파일·키 집합이 동일해야 한다
```

- 네임스페이스(파일)를 추가하면 **세 곳**을 함께 갱신한다: `src/i18n/messages.ts` 의 `MESSAGE_NAMESPACES`,
  `src/i18n/next-intl.d.ts` 의 `Messages`, `packages/ui/.storybook/preview.tsx` 의 `MESSAGES`.
- 키는 화면/컴포넌트 단위로 중첩한다(`settings.language.label`). 문장을 쪼개 이어 붙이지 않는다.
- 인자는 ICU 문법: `"inviteShareText": "… 초대 코드: {code}"`. 복수형은 `{count, plural, …}`.
  태그가 필요하면 `t.rich('key', { strong: (chunks) => <strong>{chunks}</strong> })`.
- 언어 이름(한국어 / English)은 번역하지 않고 `LOCALE_LABELS` 상수로 고정한다.
- 금액 뒤 단위("12,000원" / "₩12,000")처럼 축약 금액에 단위를 붙일 때는 `t('dashboard.won', { amount })` 를 쓴다.

### packages/ui 에서

`@uandi/ui` 컴포넌트는 `use-intl` 의 `useTranslations('ui.…')` 를 쓴다(next-intl 이 같은 `use-intl` 인스턴스를
재export 하므로 web 의 `NextIntlClientProvider` 컨텍스트를 그대로 읽는다). 훅을 쓰는 컴포넌트는 `'use client'` 가
필요하다. 옵션 목록처럼 값과 라벨이 함께 있던 상수는 **값 배열만 남기고**(`AI_TONE_VALUES`) 라벨은
`useAiPreferenceOptions` 같은 훅이 `t()` 로 채운다.

훅을 쓸 수 없는 순수 함수(`shareInviteLink`, `tourSlidesFor`)는 호출 측이 `t` 또는 번역된 문구를 인자로 넘긴다.

### 컴포넌트에서

```tsx
'use client';
import { useTranslations } from 'next-intl';

const t = useTranslations('settings');
<Header title={t('title')} />;
```

서버 컴포넌트·라우트: `getTranslations('metadata')` (`next-intl/server`).
`manifest.ts` 처럼 next-intl 컨텍스트 밖에서는 `resolveLocale` + `loadMessages` 를 직접 쓴다.

## 4. 통화·날짜 포맷

| 유틸                                         | ko                 | en             |
| -------------------------------------------- | ------------------ | -------------- |
| `formatCurrency(12000)` (`@/utils/currency`) | `12,000원`         | `₩12,000`      |
| `formatAmount(12000, 'expense')`             | `-12,000원`        | `-₩12,000`     |
| `formatCurrencyMan(12345000)`                | `1,235만`          | `₩12.3M`       |
| `formatDate(d)` (`@/utils/date`)             | `2026년 11월 12일` | `Nov 12, 2026` |
| `getPeriodLabel('monthly', c)`               | `2026년 11월`      | `Nov 2026`     |

- `@uandi/cashbook-core` 의 `formatCurrency(amount, locale = 'ko')` 는 로케일을 **인자**로 받는다(순수 패키지는 로케일을 모른다).
  web 의 `@/utils/currency` 래퍼가 `getActiveLocale()` 로 현재 값을 넘긴다.
- 날짜 포맷 문자열은 `utils/date.ts` 의 `DATE_FORMATS` 테이블에만 둔다. 컴포넌트에 `'M월 D일'` 을 직접 쓰지 않고 `dateFormat('monthDay')` 를 쓴다.
- 금액 저장은 원 단위 정수(`toWonAmount`)로 유지한다. 다통화(범위 B)로 갈 때 "통화 최소단위 정수"로 재정의하면 KRW 데이터는 그대로다.

## 5. 가드 스크립트

```bash
pnpm i18n:check      # 아래 두 검사
pnpm i18n:baseline   # 한글 하드코딩 기준선 갱신(추출 PR 마지막에)
```

| 스크립트                             | 역할                                                                                                                                               |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `scripts/check-hardcoded-korean.mjs` | 주석을 뺀 코드에 한글이 있는 줄 수를 파일별로 세어 `scripts/i18n/hardcoded-korean.baseline.json` 과 비교. **늘면 실패**(ratchet). `--list` 로 현황 |
| `scripts/check-message-parity.mjs`   | ko/en 파일·키·ICU 인자 일치, 빈 값 검사                                                                                                            |

새 UI 문자열은 반드시 메시지 파일에 넣고 `t()` 로 읽는다. 기준선을 올려야 한다면 PR 에 이유를 적는다.

## 6. 테스트

- Playwright 는 `locale: 'ko-KR'` 로 고정한다(`playwright.config.ts`, `playwright.screenshots.config.ts`).
  Chromium 기본이 en-US 라 고정하지 않으면 Accept-Language 로 영어가 떠 기존 한국어 locator 가 전부 깨진다.
- 언어 전환은 `e2e/specs/settings-language.spec.ts` 가 검증한다(전환·새로고침 유지·쿠키 삭제 후 users.locale 복원·되돌리기).
- 영어 화면은 Storybook 툴바 Locale 로 본다. 영어는 한국어보다 평균 30% 길므로 버튼·칩·탭 overflow 를 확인한다.
- 워크트리 여러 개가 한 머신에서 돌 때는 `E2E_PORT=3200 pnpm exec playwright test …` 로 포트를 바꿔 다른 워크트리의 dev 서버를 재사용하지 않게 한다.
