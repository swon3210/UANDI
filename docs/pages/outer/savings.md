# 페이지 명세: 예적금 트래커 (/outer/savings)

## 목적

예금·적금 상품을 등록해 두면 **자동이체 주기대로 납입 원금이 저절로 쌓이고**, 만기 예상 수령액(세후)을 한눈에 보여준다.

- **처음 등록할 때**: 상품 상세설명 화면을 캡처해 올리면 AI가 만기일·적용이율·입금 주기·입금액을 읽어 폼을 채운다. 사용자는 확인·수정 후 저장한다. 캡처 없이 직접 입력도 가능하다.
- **이후 사용할 때**: 자동이체 주기(매월 n일 / 매주 n요일)에 맞춰 오늘까지의 납입 회차만큼 원금이 자동으로 더해진다. 만기 예상금액은 남은 회차까지 모두 포함해 계산한다. **별도 입력·스케줄러 없이 저장된 상품 조건만으로 매번 계산**한다.

> 사이드바 항목명은 "예적금". 데이터는 개인 소유(`sideHustles/{uid}`) — 파트너는 볼 수 없다.

## 계산 규칙 (`utils/savings.ts`, 순수 함수)

- **납입 일정**
  - 예금: 가입일 1회.
  - 적금 매월: 가입일(1회차) + 가입월 다음 달부터 매월 이체일(말일 clamp), 만기일 **전날까지**.
  - 적금 매주: 가입일(1회차) + 가입일 이후 매주 지정 요일, 만기일 전날까지.
  - 납입 횟수는 가입 기간(개월 수 / 주 수)을 넘지 않는다. 예: 8/15 가입 · 매월 1일 이체 · 12개월 → 8/15, 9/1 … 7/1 (12회).
- **납입 원금(현재)** = 입금액 × (오늘 이하인 회차 수)
- **만기 원금** = 입금액 × 전체 회차 수
- **세전 이자**
  - 단리: Σ 입금액 × 연이율 × (해당 회차일 → 만기일 일수) / 365
  - 월복리: Σ 입금액 × ((1 + 연이율/12)^(일수 / (365/12)) − 1)
- **세금** = 세전 이자 × 과세율 (15.4% / 9.5% / 0%)
- **만기 예상 수령액(세후)** = 만기 원금 + 세전 이자 − 세금
- **D-day** = 만기일 − 오늘 (0 이하이면 "만기")

> 실제 은행 계산(중도 해지, 우대금리 조건, 원 미만 절사 등)과 다를 수 있으므로 카드 하단에 "예상치" 문구를 둔다.

## AI 캡처 파싱 — `POST /api/ai/parse-savings`

- 공통 AI 규칙(`05-ai-features.md`) 준수: Bearer 인증, 커플당 일일 한도, `USE_AI_MOCK` 지원.
- Request: `{ image: string }` (data URL, 클라이언트에서 압축)
- Response:
  ```ts
  {
    isSavingsProduct: boolean; // 예적금 상품 화면이 아니면 false → "상품 정보를 찾지 못했어요"
    product: {
      name: string;
      bank: string;
      productType: 'installment' | 'deposit';
      interestRate: number | null; // 연 %
      interestMethod: 'simple' | 'compound';
      termMonths: number | null;
      startDate: string | null; // YYYY-MM-DD
      maturityDate: string | null;
      depositAmount: number | null;
      depositCycle: 'monthly' | 'weekly';
      depositDay: number | null; // 매월 n일 / 요일(0=일)
      taxType: 'normal' | 'preferential' | 'taxFree';
    }
  }
  ```
- 우대금리가 여러 개면 **최고 적용 가능 이율이 아니라 기본금리 + 확정 우대금리**를 사용하도록 프롬프트에 명시.

## 데이터

- 경로: `couples/{coupleId}/sideHustles/{uid}/savings/{accountId}` (본인만, 보안 규칙 기존 `sideHustles` 규칙)
- 타입: `SavingsAccount` (`03-domain-models.md`)
- 목록 조회: `orderBy('createdAt') + limit(100)` — 개인 보유 상품은 수십 개를 넘지 않고 합계 계산에 전체가 필요해 커서 페이지네이션 예외로 둔다.
