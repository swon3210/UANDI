# 페이지 명세: 투자 (/outer/investment)

## 목적

주식·부동산 보유 자산을 등록해 두고 **시세 기준 평가손익(+/−)** 과 배당·세금을 함께 본다.

상단 `Tabs`로 **주식 / 부동산** 을 전환한다 (기본 주식).

> 데이터는 개인 소유(`sideHustles/{uid}`) — 파트너는 볼 수 없다.

---

## 1. 주식 탭

### 처음 등록할 때

- [잔고 캡처로 추가] → 증권사 잔고 화면 캡처 업로드 → `/api/ai/parse-stock-holdings` →
  `StockImportSheet`에서 추출된 종목(종목명·종목코드·수량·평균 매수가·배당 정보)을 확인하고, 빼고 싶은 종목은 제외한 뒤 일괄 저장.
- [직접 추가] → `StockHoldingForm` (종목명, 시장 KR/US, 종목코드, 수량, 평균 매수가, 주당 배당금(선택), 배당 예정일(선택)).

### 사용할 때

```
┌─ PortfolioSummaryCard ──────────┐
│ 평가금액 ₩ 12,450,000           │
│ 평가손익 +₩ 1,230,000 (+10.9%)   │
│ 오늘 −₩ 32,000 · 예상 배당 ₩ 210,000/년 │
│ 시세 기준 2026-10-26 15:30       │
└─────────────────────────────────┘
┌─ StockHoldingCard ──────────────┐
│ 삼성전자 005930 · 10주           │
│ 현재가 ₩72,000  평단 ₩65,000     │
│ +₩70,000 (+10.8%)                │
│ 배당 예정 11/15 · ₩3,610 (세전)  │
└─────────────────────────────────┘
```

- **시세**: `GET /api/investment/quotes?symbols=KR:005930,US:AAPL` (서버에서 Yahoo Finance chart API 호출, 10분 캐시).
  장중에는 지연 시세(약 15분), 장 마감 후에는 종가 기준. 응답에 시세 기준 시각(`asOf`)을 포함해 카드 하단에 표시.
  - KR 종목은 `{code}.KS` → 실패 시 `{code}.KQ` 순으로 조회.
  - 미국 주식은 `KRW=X` 환율로 원화 환산 (매수 단가도 현재 환율로 환산 — 환차익은 반영하지 않음).
- **평가손익** = (현재가 − 평균 매수가) × 수량, **수익률** = 평가손익 / 매수금액.
- **오늘 변동** = (현재가 − 전일 종가) × 수량.
- **배당**: 사용자가 입력한 주당 배당금 × 수량(+배당 예정일). 입력이 없으면 최근 1년 배당 합계(TTM) × 수량을 "연 예상 배당"으로 표시. 모두 세전.
- 종목코드가 없거나 시세 조회 실패 → 카드에 "시세 없음" 표시, 합계에서는 매수금액으로 대체.
- 카드 탭 → 수정/삭제 시트.

## 2. 부동산 탭

### 처음 등록할 때 (`RealEstateForm`)

1. 지역 선택: 시/도 → 시/군/구 (`constants/lawd-regions.ts`, 국토부 LAWD_CD 5자리)
2. 아파트명 입력 → [실거래 조회] → `GET /api/investment/apt-trades?lawdCd=&aptName=`
3. 조회된 거래의 **전용면적별 평형 칩**(전용 ㎡ · 약 N평 · 최근 거래가) 중 하나 선택
   - API 실패/미설정이면 전용면적(㎡)을 직접 입력
4. 매수가(만원), 매수일, 1세대 1주택 여부

### 사용할 때

```
┌─ RealEstateCard ────────────────┐
│ 헬리오시티 · 송파구 가락동        │
│ 전용 84.99㎡ (약 34평형)         │
│ 실거래 시세 ₩ 18억 5,000         │
│ +₩ 3억 5,000 (+23.3%)            │
│ 최근 거래 2026-10-12 · 12층       │
│ ── 예상 세금 ──                   │
│ 재산세(연) ₩ 2,840,000            │
│ 양도세(지금 매도 시) ₩ 0 (비과세)  │
└─────────────────────────────────┘
```

- **시세**: 국토교통부 아파트 매매 실거래가 API(공공데이터포털, env `DATA_GO_KR_API_KEY`)에서 최근 6개월 거래를 조회. 서버 캐시 1일(**1일 기준 실거래가**).
  - 같은 단지 + 전용면적 ±1㎡ 거래 중 최근 3건의 중앙값을 현재 시세로 사용.
  - 해제(취소) 거래는 제외.
  - 거래가 없거나 API 실패 시 사용자가 입력한 "수동 시세"로 대체, 그것도 없으면 "시세 없음".
- **평가손익** = 시세 − 매수가.
- **예상 세금** (`utils/real-estate-tax.ts`, 단순화한 추정치 — 카드에 "참고용 추정" 문구 필수):
  - 공시가격 ≈ 시세 × 69% (공동주택 현실화율 가정)
  - **재산세(연)**: 과세표준 = 공시가격 × 공정시장가액비율(1주택 43~45%, 그 외 60%).
    1주택 특례세율(공시 9억 이하) 또는 표준세율 누진 + 도시지역분 0.14% + 지방교육세(재산세의 20%). 세부담상한·종부세 미반영.
  - **양도세(지금 매도 시)**: 차익 = 시세 − 매수가(필요경비 미반영).
    - 1세대 1주택 & 2년 이상 보유: 양도가 12억 이하 비과세, 초과분만 과세 + 장기보유특별공제(보유·거주 각 연 4%, 최대 80%, 거주=보유 가정).
    - 그 외: 장기보유특별공제 3년 이상 연 2%(최대 30%).
    - 보유 1년 미만 70%, 2년 미만 60%, 그 외 기본세율(6~45%) − 기본공제 250만, 지방소득세 10% 포함.

## 데이터

| 컬렉션                                                         | 타입                |
| -------------------------------------------------------------- | ------------------- |
| `couples/{coupleId}/sideHustles/{uid}/stockHoldings/{id}`      | `StockHolding`      |

## AI 캡처 파싱 — `POST /api/ai/parse-stock-holdings`

- Request: `{ image: string }`
- Response:
  ```ts
  {
    isHoldingsScreen: boolean;
    holdings: {
      name: string;
      symbol: string; // 모르면 '' (국내 6자리 코드 / 미국 티커)
      market: 'KR' | 'US';
      currency: 'KRW' | 'USD';
      quantity: number;
      averagePrice: number; // 평균 매수 단가 (통화 기준)
      dividendPerShare: number | null;
      nextDividendDate: string | null;
    }
    [];
  }
  ```
- 화면에 종목코드가 없으면 널리 알려진 종목에 한해 모델이 코드를 채우고, 확신이 없으면 ''로 둔다 (사용자가 수정).

## E2E 시나리오 (`e2e/specs/outer-investment.spec.ts`)

시세·실거래 API는 `page.route()`로 모킹, AI는 `USE_AI_MOCK`.

| 시나리오                                    | 기대 동작                                            |
| ------------------------------------------- | ---------------------------------------------------- |
| 주식 탭 빈 상태                             | EmptyState + 추가 버튼                               |
| 잔고 캡처로 추가 (AI mock)                  | 미리보기 시트에 종목 2개 → 저장 → 카드 2개           |
| 저장된 종목 + 시세 mock                     | 평가손익 +/− 금액·수익률, 합계 카드 표시             |
| 종목 수정·삭제                              | 반영                                                 |
| 부동산: 지역·아파트 조회 → 평형 선택 → 저장 | 카드에 실거래 시세·평가손익·재산세·양도세 표시       |
| 실거래 API 실패                             | 전용면적 직접 입력으로 저장 가능, 카드에 "시세 없음" |
